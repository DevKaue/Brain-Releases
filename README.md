# Brain Desktop

Repositório público de instaladores e atualizações assinadas do Brain. O código-fonte é mantido separadamente em repositório privado. Dados pessoais, contas, bancos e chaves ficam fora da distribuição.

## Estado

Canal em preparação. A primeira release assinada ainda depende da configuração final e do ensaio de instalação/atualização. Consulte a página de Releases quando a versão estiver disponível.

## Atualizações

O aplicativo verifica releases no início e a cada seis horas, valida assinatura e versão e exige snapshot antes de instalar. A assinatura do updater é independente de Authenticode do Windows.

## Sincronização

Para reunir desktop e notebook, configure um Brain central HTTPS e pareie cada pasta autorizada. Conteúdo de trabalho local-only permanece na máquina de origem.

## Suporte

Use as Issues deste repositório para relatar problemas. Não inclua notas privadas, conversas, senhas, tokens ou chaves nos relatos.
